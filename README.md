# Compound-impacts-of-sea-urchin-grazing-and-MHWs-on-kelp
Data and Code for the research of the Compound impacts of sea urchin grazing and marine heatwaves (MHWs) on kelp collapse along east coast of Australia.

Due to their size, raw datasets must be accessed directly from the providers. However, all datasets are freely available, and the instructions below explain exactly how to download them and where to place the files; links are also provided inline in the relevant code files. The MHW data preparation and metrics analysis were computed in Python (v3.0). All the species data curation and model regression analyses were performed using R Statistical Software (v 4.3.3; R Core Team 2024). MHW calculations are performed using xmhw: https://github.com/coecms/xmhw.

### Processed data and source files
| Data Folder | Description |
|-----:|---------------|
| CMIP6 | CMIP6 source lists for historical and SSP5-8.5 scenario data |
| glmm_input | Input data for the binomial GLMM projection of kelp collapse probability: changes in urchin density and MHW maximum intensity, including the high-emission scenario for 2090–2100  |
| glmm_input | Location-level GLMM projections of the change in kelp collapse probability, with Monte Carlo uncertainty, under different scenarios of urchin density and MHW intensity |

### Code files
| Code File | Description |
|-----:|---------------|
| `kelp_atrc_rls_surveyid.R` | RLS Kelp (*Ecklonia radiata*) canopy cover data curation into survey_id level, and merged with the ATRC kelp cover dataset. |
| `urchin_kelp_surveyid.R` | Urchin (*Centrostephanus rodgersii*) density data curation into survey_id level for both RLS and ATRC programs, followed with combining the urchin and kelp data with same survey_id |
| `mhw_metrics_each_survey.ipynb` | Compiling *Ecklonia* cover and *Centrostephanus* density, and MHW metrics annually |
| `boxplots_timeseries.ipynb` | Time period series of *Ecklonia* cover and *Centrostephanus* density, and MHW maximum intensities -- Fig.1b |
| `ob_glmm_kelp_urchin_mhwintensity.R` | Relationship bwteern *Ecklonia* cover and *Centrostephanus* density using ordered-beta GLMM, under different MHW maximum intensities levels, followed with convergence and residual checks -- Fig.2a, Fig S2-3 |
| `urchin_distribution_collapse_propotion.ipynb` | Latitudinal distribution of *Centrostephanus* density and propograted kelp resilience propotions -- Fig.2b |
| `kum_glmm_mmselection.R` | Multi-model selection of Binomial GLMM regression of kelp collapse probablity with urchin density and MHW metrics, followed with cross validation, kelp collapse threshold sensitivity check, probability scale contrast calculation, projection calculation for input of different scenarios -- Fig.3, Table S3-7 |
| `compute_cmip6_index.py` | Compute CMIP6 historical + future SST timeseries for case study regions |
| `cmip6_glmm_input.ipynb` | Calculating mhw intensity as input for binomial GLMM projection of kelp collapse probablity change in 2090s under CMIP6 SSP585 scenario, and combined with urchin density projection from Davis et al. (2023) -- Fig.S4, Table S9 |
| `location_glmm_projection_bar.ipynb` | Binomial GLMM projection of the deviation with present-day condition of kelp collapse probablity under different scenarios, including assumed scenarios of increasing urchin densities and max intensities, and 2090s (Davis et al. 2023) -- Fig.4 and S5 |
